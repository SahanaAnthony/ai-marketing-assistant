# AI Marketing Assistant (n8n)

This project is a multi-agent AI system built using n8n and OpenRouter.

## Features
- Ad Copy Generator
- Campaign Generator
- Customer Persona Generator
- Review Response Generator
- WhatsApp Message Generator

## Tech Stack
- n8n
- OpenRouter (LLM API)

## Workflow
Webhook → Set → 5 AI Agents → Merge → Function → Response
